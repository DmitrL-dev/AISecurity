# Public entry artwork

`aisecurity-hero.webp` and `aisecurity-banner.webp` were generated for this project
with OpenAI's built-in image generation tool on 2026-09-08, then encoded as WebP
without changing their composition. They use the same optical-boundary visual:
three smoked-glass planes, mint light passing through and an amber ray refracting.

The images are conceptual artwork, not a product screenshot, live scan,
performance measurement or claim that any defense is perfect. The hero has no
text; its page heading and navigation are real HTML. The README banner has
redundant text alternatives in the surrounding Markdown.

Design brief: dark editorial research laboratory, restrained glass materials,
readable typography, no stock shield, hacker imagery, dashboard or invented
metrics. Banner text: “AISecurity”, “Understand the attack.”, “Build the defense.”,
“LEARN / INSPECT / EVALUATE”. No private source, datasets or customer content was
provided for generation. These project assets follow the repository license;
the product name does not grant additional trademark rights.

The older `sentinel_hero.png` and `academy_evolution.png` are preserved unchanged.
