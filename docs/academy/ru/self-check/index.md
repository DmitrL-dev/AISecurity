# Экзамены для самопроверки

> **Только для самопроверки.** Эти экзамены помогают проверить собственное понимание. AISecurity не ведёт программу сертификации: сертификаты, значки и верифицируемые записи не выдаются, а результат не подтверждает квалификацию для работодателя, заказчика или аудитора.

| Экзамен | Требования | Темы |
|---------|-----------|------|
| [Начинающий](beginner-exam.md) | Трек начинающего | Основы инъекций, OWASP, первая интеграция |
| [Средний](intermediate-exam.md) | Средний трек | Векторы атак, production, SIEM |
| [Продвинутый](advanced-exam.md) | Продвинутый трек | TDA, разработка движков, анализ CVE |
