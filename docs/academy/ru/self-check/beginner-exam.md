### Вопрос 2

Какую проблему RNN решает механизм Self-Attention?

- [ ] A) Недостаточно параметров
- [ ] B) Последовательная обработка и затухание градиентов
- [ ] C) Слишком быстрое обучение
- [ ] D) Слишком много обучающих данных

<details>
<summary>✅ Ответ</summary>

**B)** Self-Attention позволяет параллельную обработку и прямой доступ ко всем позициям, решая проблемы последовательной обработки и затухающих градиентов.

</details>

### Вопрос 3

Что такое токенизация в контексте LLM?

- [ ] A) Шифрование данных
- [ ] B) Разбиение текста на подсловные единицы
- [ ] C) Генерация случайных чисел
- [ ] D) Сжатие модели

<details>
<summary>✅ Ответ</summary>

**B)** Токенизация — процесс разбиения текста на токены (подсловные единицы), которые модель может обрабатывать.

</details>

---

### Вопрос 4

Какова роль Query, Key, Value в механизме Attention?

- [ ] A) Query — вопрос, Key — ключ поиска, Value — возвращаемое значение
- [ ] B) Query — база данных, Key — пароль, Value — результат
- [ ] C) Это синонимы одной концепции
- [ ] D) Используются только для шифрования

<details>
<summary>✅ Ответ</summary>

**A)** Query определяет что мы ищем, Key — что есть в каждой позиции, Value — что возвращается при совпадении.

</details>

### Вопрос 5

Почему Transformer использует Positional Encoding?

- [ ] A) Для ускорения обучения
- [ ] B) Для добавления информации о порядке токенов
- [ ] C) Для уменьшения размера модели
- [ ] D) Для шифрования входных данных

<details>
<summary>✅ Ответ</summary>

**B)** Transformer обрабатывает токены параллельно и без positional encoding не знает их порядок.

</details>

### Вопрос 6

Что отличает Encoder от Decoder в Transformer?

- [ ] A) Encoder использует больше памяти

- [ ] C) Encoder работает быстрее
- [ ] D) Нет различий

<summary>✅ Ответ</summary>

</details>

### Вопрос 9

Что такое Temperature в генерации LLM?
