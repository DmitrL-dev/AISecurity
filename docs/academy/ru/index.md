# AISecurity Academy

**[English version](../en/index.md)** · [Главная проекта](https://dmitrl-dev.github.io/AISecurity/) · [Spectorn](https://spectorn.ai/)

**Разберитесь, где AI-система пересекает границу доверия — и что там может пойти не так.**

Начните с конкретной угрозы, проследите её до публичной реализации, затем переходите
к упражнениям. Для чтения академии ничего устанавливать не нужно.

## Проверьте гипотезу на публичном ядре

Для оценки размеченных входов откройте
[инструкцию по установке и демо Guard Lab](../../../tools/guard-lab/README.md#install-linux-x86-64--python-311).
Он отдельно показывает пропуски, ложные срабатывания и ошибки исполнения, не включая
в отчёт исходные тексты. Начните с Linux x86-64 и Python 3.11: установка собирает
нативный код и скачивает зависимости. Аккаунт, API-ключ и GPU не нужны.
Небольшое синтетическое демо проверяет запуск, **а не качество детекции**.

настоящие секреты и приватные данные клиентов. Об уязвимостях сообщайте по
[политике безопасности](../../../SECURITY.md).
