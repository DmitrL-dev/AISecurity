# Quick Start

> **Archived.** The legacy SENTINEL platform quick start (Docker Compose stack,
> install scripts and Python API examples) was never revalidated and has been
> retired from this page. `install.sh` and `install.ps1` were removed. The old
> text remains in Git history. `Dockerfile` and `docker-compose.yml` are kept only
> as archived files.

## Supported path: Guard Lab

For local input evaluation without a hosted service, use the
[Guard Lab installation guide](tools/guard-lab/README.md). It has its own
Python environment, a pinned public native dependency and a synthetic demo.

## Public core

The Rust/Python pattern core in [`sentinel-core/`](sentinel-core/README.md) is a
frozen legacy snapshot. Its README documents how to build it.

## Learn first

No installation is needed for the [academy](docs/academy/en/index.md)
([на русском](docs/academy/ru/index.md)) or the
[60-second agent decision room](https://dmitrl-dev.github.io/AISecurity/agent-action-room.html).
