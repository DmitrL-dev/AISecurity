Код — основа любого проекта

Удобство работы с кодом напрямую влияет на скорость выпуска IT-продуктов, поэтому мы уделили особое внимание фичам, облегчающим жизнь разработчиков.

Надежный ИИ-ассистент разработчика

Встроенный ИИ-помощник SourceCraft Code Assistant помогает писать код через подсказки и автодополнение. Агентский режим автоматизирует процесс разработки от идеи до развертывания программных продуктов в Yandex Cloud. Он поможет создать задачу, написать код, сгенерировать автотесты, проверить безопасность, подготовить пулл-реквест и запустить развёртывание на облачной платформе по единому запросу пользователя.

Моментальная навигация по коду

Быстрая и удобная навигация по кодовой базе и пулл-реквестам с функциональностью 'go to declaration', 'find usages', 'quick info' для максимального удобства и сокращения времени на код-ревью. Навигация по коду теперь работает с языками C# и Kotlin, а также с файлами, которые используются для создания и отладки программного обеспечения.

Создавайте / Собирайте / Раскатывайте

В SourceCraft есть нужные инструменты для автоматизации сборки и поставки кода, в том числе готовые «кубики» для самых распространённых задач прямо в интерфейсе платформы. Вы можете гибко планировать запуск автоматизаций в связке с циклом разработки (от ревью веток до авторазвёртывания).

Повышайте безопасность проектов

Инструменты безопасности позволят IT‑специалистам совершать меньше ошибок при разработке и создавать безопасное программное обеспечение:

  • Сканер секретов в коде
  • Анализ зависимостей в кодовой базе
  • Сводная статистика по найденным ИБ‑рискам

О рисках система сообщает на этапе написания кода, до попадания изменений в рабочую версию приложения.

Интеграция с облаком и CI/CD

При задачах CI/CD теперь можно автоматически получать доступ к облачным сервисам Yandex Cloud: создавать виртуальные машины, загружать данные в S3, настраивать базы данных.

Приложения можно развернуть на Serverless Containers, масштабируемых серверах облака или на своём оборудовании. Добавили поддержку GitHub Actions: при переносе проекта не нужно переписывать сценарии автоматизации — SourceCraft преобразует готовые настройки в свой формат.

Вопросы и ответы

SourceCraft — это платформа для разработки приложений, которая помогает качественно и удобно проводить код-ревью, управлять версиями автоматизированной сборки, тестировать, развёртывать и сопровождать программные продукты. Платформа поддерживает полный цикл работы с кодом и подходит индивидуальным разработчикам, контрибьюторам в опенсорс-проекты, а также IT-компаниям любого размера.

Платформа доступна для всех желающих в режиме General Availability. Для регистрации на платформе нажмите на кнопку Войти. Для авторизации в SourceCraft вам потребуется аккаунт Yandex ID (на @yandex.ru).

Платформа позволяет не только хранить код и управлять версиями, но и собирать, тестировать, разворачивать и сопровождать программные продукты в едином интерфейсе. Мы предоставляем надёжное и безопасное решение, интегрированное с облачной платформой, с улучшенной кодонавигацией и помощью ИИ-агента.

Можно просто и быстро перенести репозитории или настроить зеркалирование с других площадок.
